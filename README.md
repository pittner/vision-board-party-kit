# Vision Board Party Kit 2027

Free printable kit for hosting a two-hour vision board party: 12 prompt cards on one A4 / US Letter sheet (with a QR code to a free phone version), a timed agenda, invitation text and a supply list.

**Live page:** https://pittner.github.io/vision-board-party-kit/

- Print from the browser or download SVG / PNG (A4 at 200 dpi)
- No signup, no e-mail, MIT licensed
- Guests without magazines: [free vision board maker](https://visionboard.bemooore.com/free-vision-board-maker/?mode=wallpaper&utm_source=github_readme&utm_medium=referral&utm_campaign=party_kit_2027) makes a 1080x1920 lock-screen wallpaper in the browser

Rebuild: `pip install segno && python3 build.py`
